# Product Context Template

Every skill in this pack reads one file: `product-context.md`, kept at the root of the working folder (next to `clusters/`). It is the single source of truth for what the product is and what it can do.

If `product-context.md` does not exist, copy this template, then fill it in with the user before any planning or writing. Ask for the sections in one short intake, not one question at a time.

**The verified-only rule.** If a feature, customer, number or integration is not written in this file, the product does not have it. Writers must refuse to claim it. Every fact below should carry the URL it was verified from and the date it was checked.
